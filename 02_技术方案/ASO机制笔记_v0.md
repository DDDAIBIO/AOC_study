## 一句话结论

ASO 只有**两种**作用模式：**降解型**（RNase H1 / gapmer，把靶 mRNA 切掉）与**占位型**（立体位阻，只挡住某个位点、改变剪接）。两者在化学设计上**互斥**——这是最容易搞混的地方。

---

## 模式一：RNase H1 降解（gapmer）

- **架构**：5-10-5（两翼修饰 RNA / 中央 DNA gap / 两翼修饰 RNA），全长 PS 骨架
- **为什么中央必须是 DNA**：RNase H1 只识别 **DNA/RNA 杂合链**，RNA/RNA 双链不切
- **为什么两翼必须修饰**：裸 DNA 亲和力低（Tm 不够）+ 易被核酸酶降解；2′-MOE 补上这两点
- **关键性质**：RNase H1 是酶 → 一条 ASO 可**催化**切割多条 mRNA（turnover），非一换一
- **典型药物**：Mipomersen、Inotersen、Volanesorsen（肝/全身给药为主）

## 模式二：剪接位阻（立体位阻）

- **不降解任何东西**，只是"占住"某个调控元件，改变剪接结果
- **Nusinersen / SMN2 这条线**：
  - SMA 患者缺 SMN1，靠备份基因 SMN2 顶；但 SMN2 有个 **c.840C>T**（同义突变），破坏 exon 7 上的剪接增强子 → exon 7 被跳过 → 截短蛋白 Δ7-SMN（不稳定、迅速降解）
  - **ISS-N1** 是 intron 7 里的"剪接沉默元件"，hnRNP A1 结合它 → 抑制 exon 7 纳入
  - Nusinersen（18-mer）**精确占据 ISS-N1** → hnRNP A1 挤不上去 → exon 7 保住 → 全长 SMN 蛋白
- **⚠️ 最重要的一条**：剪接调控 ASO **绝不能有 DNA gap**——否则会招募 RNase H 把 pre-mRNA 切掉，机制直接反了。所以它**全长 2′-MOE + PS，无 gap**。

> 这与模式一正好是"一个结构决定一个机制"的对照：**有 gap = 降解，无 gap = 占位**。

## 案例拆解 1/3：Nusinersen（Spinraza）

> 统一模板：靶点与疾病 → 序列与化学 → 递送 → 剂量 → 安全性 → 计算切入点

| 维度 | 内容 |
|---|---|
| 靶点与疾病 | SMN2 基因 intron 7 的 ISS-N1；脊髓性肌萎缩症（SMA） |
| 序列与长度 | 18-mer（分子式 `C234H323N61O128P17S17Na17`，**P/S 各 17 个 → 18 nt**），MW 7501 Da |
| 化学 | 全长 **2′-MOE** + 全长 **PS**；**无 DNA gap**（占位型） |
| 递送 | **鞘内注射（intrathecal）**——ASO 不跨血脑屏障，靶器官是 CNS，直接打进 CSF |
| 剂量 | 负荷期 0/14/28/63 天各一针，之后**每 4 个月**维持 |
| 安全性 | 血小板减少、肾毒性（尿蛋白 58% vs 对照 34%） |

**三个自己算一遍就有感觉的数字**：

1. P/S 各 17 → 18 个核苷酸（每个磷酸二酯键 1 个 P、1 个 S；n 个核苷酸有 n−1 个键）
2. CSF 半衰期 **135–177 天**、血浆 63–87 天 → 这就是"每 4 个月一针"的来源
3. MW 7501 Da —— 记住 ASO 是 **~7 kDa 这个量级**，对比抗体 ~150 kDa，siRNA ~14 kDa

## 计算切入点（今天想到的）

- **gapmer 设计 = 三个自由度**：gap 放在靶 mRNA 的哪一段（可及性）、gap 多长、翼部用什么修饰。这是可以建模的。
- **占位型设计的核心约束是"别切"**：只要序列里没有 DNA gap，就不会误伤——这个约束极其干净，适合写成校验规则（后面做管线时可以直接断言）。
- **剪接调控靶点的发现**依赖 RNA-seq / 剪接异构体定量——这是我十年生信最直接的迁移点。

## 自检答案（先自己想，再对）

<details>
<summary>点开看</summary>

1. **为什么 gapmer 中间必须是 DNA？** RNase H1 只切割 DNA/RNA 杂合链中的 RNA 链；全 RNA 双链不识别。
2. **为什么两翼要 2′-MOE？** 裸 DNA 的 Tm 太低（结合不牢）、且易被核酸酶降解；2′-MOE 提高 Tm 与核酸酶抗性。
3. **为什么 Nusinersen 不能有 DNA gap？** 有 gap 就会招募 RNase H1 降解 SMN2 pre-mRNA，与"让 exon 7 保留"的目标完全相反。
4. **为什么靶点是内含子而不是 exon 7 本身？** 要结合在调控元件（ISS-N1）上才能挡住 hnRNP A1；结合外显子序列改变不了剪接决定。
5. **为什么鞘内注射而不是静脉？** ASO 不跨血脑屏障，靶器官是 CNS。
